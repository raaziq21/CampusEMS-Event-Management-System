Academic Architecture Overview

About Campus Event Management System

A full-stack, secure web platform developed for BCA Cybersecurity academic evaluation.

Project Objective

The primary objective of this project is to architect a production-grade, three-tier Event Management System (EMS) designed for university and college campuses. It bridges the communication gap between student participants, faculty event organizers, and collegiate administrators while upholding strict cybersecurity standards.

Cybersecurity Highlights

Cryptographic Password Hashing: Passwords are encrypted before database persistence using bcrypt with 10 salt rounds. Plain text credentials are never stored or logged.
JWT Stateless Authentication: Authenticated sessions rely on digitally signed JSON Web Tokens passed via HTTP Authorization headers.
Strict Role-Based Authorization: Protected endpoints verify roles (Admin, Organizer, Participant) directly on the Express server middleware layer, rather than relying on frontend view hiding.
Database Level Uniqueness & Race Prevention: MongoDB compound unique indexes guarantee that participants cannot double-book event seats.
